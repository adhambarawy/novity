# Novity Value Proposition Analysis

## Overview

Novity sells **predictive maintenance AI for industrial rotating equipment** in process industries. Their core offering is TruPrognostics™, an AI platform that diagnoses machine faults, identifies root causes, forecasts time-to-failure, and recommends specific maintenance actions.

## Core Value Proposition

**"An AI that tells you when your machines will fail and what to do about it."**

Novity transforms reactive maintenance into proactive, data-driven decision-making by:
- Diagnosing faults with actionable insights
- Identifying root causes with multiple hypotheses
- Forecasting remaining useful life (RUL)
- Recommending specific next steps based on OEM manuals and SOPs

## Key Differentiators

### 1. Actionable Diagnostics (Not Just Detection)
- Most tools detect anomalies; Novity predicts failures
- Outputs include: fault diagnosis, root cause hypotheses, recommended actions, RUL forecasts
- Every output is documented per fault mode and data tier so engineers know what to expect
- Eliminates guesswork—engineers can act with confidence

### 2. Hybrid AI Architecture
Combines three AI approaches:
- **Physics**: Encodes how machines fail (domain knowledge)
- **Machine Learning**: Detects deviations from normal operation
- **Contextual AI**: Identifies root causes and translates them into specific actions

This prevents hallucinations by constraining reasoning to OEM manuals, customer SOPs, and prior work history.

### 3. Sourced Recommendations
- Every action cites the manual or SOP it came from
- Reasoning is constrained to trusted sources
- No AI-generated guesses or unsupported recommendations

### 4. Proven Production Results
- **92–93% fault detection rate** across validated fault modes
- Low false alarm rate
- Performance validated in production against customer-confirmed concurrent events
- **Real case**: Flagged a developing fault on a reciprocating compressor **40+ days before** the customer's existing monitoring would have caught it
- No emergency callout, no production loss

### 5. Flexible Data Tiers
Start with data you already have; add sensors for more precision:

| Tier | Data Source | Capabilities |
|------|-------------|--------------|
| **Base** | PI/time-series from historian | Process-domain diagnostics, efficiency loss detection, compression changes, bearing conditions |
| **Plus** | Base + one high-frequency vibration sensor | Precise mechanical diagnostics, valve leakage, oil whip detection |
| **Premium** | Multiple high-frequency sensors | Individual valve identification, crosshead wear, rider band wear |

No new software deployment required—integrates with existing historian data.

## Asset Coverage

Novity covers critical rotating and process equipment:
- Reciprocating Compressors (valves, packing, bearings, rod condition)
- Centrifugal Compressors (stage efficiency, bearing wear, leakage, oil whirl)
- Centrifugal Pumps (cavitation, impeller wear, bearing decline)
- Electric Motors (windings, eccentricity, bearing faults)
- Industrial Fans & Blowers (imbalance, blade wear, bearings)
- Heat Exchangers (performance and fouling from process data alone)
- Also covers: turbines, gearboxes, generators, and other rotating equipment

## Target Market

**Primary**: Process industries with critical rotating equipment where unplanned downtime is expensive
- Oil & gas (energy supermajors)
- Petrochemicals
- Utilities
- Manufacturing

**Customer Profile**: Operations teams managing expensive, mission-critical equipment that cannot afford emergency shutdowns

## Business Model

- **Proof of Value**: 30-minute scoping conversation to evaluate on customer's own historian data
- **Flexible Deployment**: Start with Base tier (existing data), upgrade to Plus/Premium as needed
- **Integration**: Works with existing PI historians and data systems

## Competitive Advantages

2. **Production Validation**: Real-world proof from energy supermajors, not just lab results
3. **Actionable Output**: Specific recommendations tied to OEM manuals, not abstract alerts
4. **Low Barrier to Entry**: Start with data you already have; no new infrastructure required
5. **Risk Mitigation**: Prevents costly emergency maintenance and production losses

## Key Metrics

- **Detection Rate**: 92–93% across validated fault modes
- **Lead Time**: 40+ days advance warning (case study)
- **False Alarm Rate**: Low (validated in production)
- **Time to Value**: Day-one value at Base tier with existing historian data
